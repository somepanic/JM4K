# JellyMod for Kodi (JM4K)

JellyMod lets you browse and play the films and series on your [Jellyfin](https://jellyfin.org) media server from Kodi.

**Status: early development.** JellyMod does not connect to Jellyfin yet. It is being changed over from SM4K and Plex Uno
step by step, so don't install it for everyday use.

## Where it comes from

JellyMod builds on [SiloMod for Kodi](https://github.com/samtheruby/SM4K) (SM4K) and
[Plex Uno](https://github.com/FilHarr/plex-for-kodi) by FilHarr, which is a reworked fork of
[PlexMod for Kodi](https://github.com/pannal/plex-for-kodi) (PM4K) by pannal, which grew out of Plex's own Kodi
add-on. JellyMod keeps those screens and replaces the server layer with one that talks to Jellyfin.

## Installing

Not available yet. Releases will come through a Kodi repository, and this page will say how to add it.
